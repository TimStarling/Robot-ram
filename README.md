# Robot RAM

本仓库用于记录基于 CANopen 协议与 DS402 子协议的巨蟹机械臂上位机驱动程序设计资料。

## 目标平台

目标运行平台为 Orange Pi 5：

- 架构：AArch64
- CPU：Cortex-A55 / Cortex-A76 级别核心
- 内存：16 GB

调试平台可使用 Windows 10 或 Ubuntu 22.04 的 x86 主机。

## 开发标准

- 语言：C++17
- 注释：Doxygen 风格
- 编码：UTF-8
- 对外库接口：C 风格接口
- 输出形式：可按需求封装为 Pybind11 库、C++ 库或可执行程序

## 设计方向

驱动程序需要读取 CSV 文件，便于复现机械臂动作序列。后续可能扩展运动学、示教、日志记录和 CAN 帧收发追踪等能力。

机械臂通过 1 Mbps CAN 总线通信，单条机械臂通常包含 6 个电机，电机位于同一条总线上。上位机通过串口转 CAN 芯片接入总线，需要按照转换芯片协议封装特殊串口帧，再由芯片转换为原生 CAN 帧。

## 线程模型

整体设计考虑三个主要线程：

1. 接收线程：接收串口侧 CAN 帧，解析消息类型，更新位置、速度、电流等共享状态。
2. 发送线程：按顺序发送 SDO/PDO 帧，避免总线竞争。
3. 规划线程：生成目标值和动作队列，供发送线程调度。

为了保证总线安全，发送必须保持单线程，避免并发发送导致冲突。
